# Mu Server conformance validation

Run the [independent h2spec and Autobahn campaign](independent/README.md) against clean Mu3/Mu4 checkouts. It records tool and build identities, individual verdicts and complete-case coverage, and supports focused replays and Java 11/17/21/25.

Issues and PRs should explain the affected behavior, reproduction, expected result and validation without relying on a private conversation. Related links supplement that explanation.
